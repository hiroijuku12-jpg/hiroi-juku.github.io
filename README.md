# 広島大学医学部生のオンライン家庭教師サイト

## ファイル
- `index.html` : トップページ、指導内容、講師紹介、FAQ、問い合わせ
- `style.css` : デザイン・スマートフォン対応
- `robots.txt` : クローラー向け設定
- `sitemap.xml` : サイトマップ
- `README.md` : 公開手順

## GitHubにアップロードする
このリポジトリ `hiroi-juku.github.io` の「Add file」→「Upload files」から、ZIPを展開した中身のファイルをアップロードしてください。
既存の `README.md` は置き換えて構いません。コミット後、GitHub Pagesの設定が有効なら更新が反映されます。

## Google検索の準備
Google Search Console: https://search.google.com/search-console/
公開URL `https://hiroi-juku.github.io/` を登録し、所有権を確認して、`https://hiroi-juku.github.io/sitemap.xml` をサイトマップとして送信してください。
検索順位は保証されず、コンテンツ改善を続ける必要があります。

## 公開前の確認
- 講師紹介、対応科目、指導条件が実際と一致するか確認してください。
- メールリンクを実際の端末でテストしてください。
- GitHub Pagesは静的サイトです。メールリンクはメールアプリを開くだけで、フォーム内容をサイト側に保存しません。
- `style.css` のフォント読み込みにGoogle Fontsを使用しています。ネットワーク状況によっては端末標準フォントに切り替わります。
